# JavaScript CRUD App with Validation, Pagination, Search, and LocalStorage

A dynamic and interactive web application built with **HTML**, **CSS**, and **Vanilla JavaScript** that allows users to perform full **CRUD (Create, Read, Update, Delete)** operations. The app features **form validation**, **pagination**, a **real-time search bar**, and data persistence using the **browser's localStorage**.

---

## 🔗 Live Demo

👉 https://mkaleemdev.github.io/crud-JS

---

## ✅ Features

- ✅ Add new records with name, mobile number, email, date of birth, and branch
- 🛠️ Real-time **form validation**
- 🗂️ Fully functional **CRUD operations**
- 🔎 Instant **search/filter** feature
- 📄 Client-side **pagination** for large datasets
- 💾 Data stored in **localStorage**, no backend needed
- 🎨 Clean and responsive UI design
